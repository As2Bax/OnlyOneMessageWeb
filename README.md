# OnlyOneMessageWeb

OnlyOneMessageWeb is the official web frontend for OnlyOneMessage. It handles the documentation, home page, terms of service, privacy policy and more.
You can view this site at https://onlyonemessage.as2bax.dev.

This website is built with **Astro**, a web framework.

*This repository is not to be confused with **[OnlyOneMessage](https://github.com/As2Bax/OnlyOneMessage)**, the source code for the bot.*


## 🖥️ Installation

This guide is for installing the website for **development purposes**. If you'd to self-host the **bot**, view this page instead: https://github.com/As2Bax/OnlyOneMessage

### Prerequisites
- Node.js (v18+)

## Instructions

1. Clone the repository:
```bash
git clone https://github.com/As2Bax/OnlyOneMessageWeb.git
cd OnlyOneMessageWeb
```

2. Use the table of commands below for instructions:

| Command                      | Action                                           |
| :---------------------------- | :----------------------------------------------- |
| `npm install`                 | Installs dependencies                            |
| `npm run dev`                 | Starts local dev server at `localhost:4321`      |
| `npm run build`               | Build your production site to `./dist/`          |
| `npm run preview`             | Preview your build locally, before deploying     |
| `npm run astro ...`           | Run CLI commands like `astro add`, `astro check` |
| `npm run astro -- --help`     | Get help using the Astro CLI                     |
