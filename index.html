❓ What is OnlyOneMessage?

OnlyOneMessage allows your server members to send a one-time message in a designated channel. Once someone sends a message, they will automatically receive restrictions within that channel.

💪 Fully Customizable

OnlyOneMessage provides lots of customization options to fit your server's needs:

• ⌛ Setup blacklist duration where members will automatically be unblacklisted after a specified time
• 🔄️ Enable message deletion recovery so users can regain access by deleting their message
• 📰 Setup logging for the latest updates your server admins or members do with OnlyOneMessage
• ✨ Enable whitelisting where admins can bypass OnlyOneMessage restrictions

Whether you want to limit spam, control message flow, or have fun, OnlyOneMessage is the perfect solution for your server!

🛠️ How it Works

  1. Once someone sends a message in a specified channel, they will automatically receive a role, @OnlyOneMessageBlacklist.
  2. The @OnlyOneMessageBlacklist role restricts members from sending messages, creating & sending messages in threads and creating reactions in the specified channel
  3. Members can be automatically unblacklisted after a set time, up to 30 days (Configuration specified)
  4. Or they can delete their own message to regain another message to send (Also configuration specified)

⚡ Get Started

  1. Invite OnlyOneMessage to your Discord server
  2. Use /setup, then press Confirm
  3. OnlyOneMessage will setup everything for you
  4. Use /remove to undo changes OnlyOneMessage has made
  5. Use /config to customize OnlyOneMessage to your liking
  6. Have fun! :D If you need support, join our support discord at the top of this page.

📋 Available Commands

OnlyOneMessage provides a variety of commands to help you manage your server and customize bot behavior:

  1. /help — View all commands and support information
  2. /setup — Setup OnlyOneMessage for your server
  3. /remove — Undo any configurations made by OnlyOneMessage

  4. /config — Customize OnlyOneMessage’s settings
  5. /modify — Manage blacklist/whitelist roles for server members

  6. /invite — Get an invite link to add OnlyOneMessage to other servers
  7. /feedback — Send bug reports, suggestions, or feedback directly
  8. /stats — View real-time bot statistics and metrics
