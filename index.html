OnlyOneMessage allows you to create a special one-message channel where members can share a single message, and that's it. After they post, OnlyOneMessage automatically restricts permissions to the member within that channel.

✨ Features

OnlyOneMessage offers a collection of features designed to enhance your Discord server's experience, whether you're controlling message flow or having fun.

😇 Whitelisting

Whitelist admins so they're never restricted by OnlyOneMessage.

📰 Logging

Send all actions to a dedicated channel and filter events by category for easy moderation.

⌛ Automatic Unblacklist

Automatically remove restrictions after 3 hours up to 1 month.

✅ Easy to Use

Set up OnlyOneMessage entirely in Discord using /setup and /config; no dashboard needed.

🗑️ Message Recovery

Let members regain access to the channel if their message is deleted.

🛠️ Full Customization

Configure everything easily with /config, featuring an interactive UI powered by Discord's latest Components V2.

⚡ Get Started

Getting started with OnlyOneMessage is easy. Follow these 3 steps and you'll be ready in no time!

1. Invite OnlyOneMessage

How can you use OnlyOneMessage when you haven't invited it? Click the Invite button to add it to your own server.

2. Use the /setup Command

In your server, run the /setup command; OnlyOneMessage will do everything for you.

3. Customization

Everything else is now on your hands; Customize the OnlyOneMessage channel, whitelist your admins, you name it! And the final step; have fun!

⚙️ How It Works

OnlyOneMessage's work style is very simple, really!

1. Blacklisting

When a non-whitelisted member sends a message in the OnlyOneMessage channel, they're instantly assigned the @OnlyOneMessageBlacklist role.

2. Restriction

Once blacklisted, the member is restricted from sending messages, creating threads, or adding reactions in that channel, and a ⛈️ reaction is added to mark their message.

3. Restoration

A member's restrictions are lifted once their blacklist role is removed, whether by an admin, through message recovery or automatic unblacklist.
