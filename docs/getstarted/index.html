Getting Started

This is a simple guide on how to get started with OnlyOneMessage, from inviting the bot to what to do next, in complete detail.

💡

OnlyOneMessage is a Discord bot that allows members to send a single message in a chosen channel.

1. Invite OnlyOneMessage

You can invite OnlyOneMessage in a lot of ways, including on this website, top.gg, or right here.

OnlyOneMessage will ask you for these permissions when inviting it:

  • Add Reactions - Used for blacklist statuses.
  • Manage Channels - Allows creation of the OnlyOneMessage channel.
  • Manage Roles - Allows OnlyOneMessage to create blacklist/whitelist roles and assign them to members.
  • Manage Threads - Used to deny threads permissions.

The Discord invite menu for OnlyOneMessage.

2. Use /setup

/setup automatically configures your server for OnlyOneMessage to function.

Once this command is run, OnlyOneMessage will send a confirmation embed, showing what it'll do:

  • Channels - If a custom channel is set, no channel will be created. Otherwise, one will.
  • Roles - The roles @OnlyOneMessageBlacklist and @OnlyOneMessageWhitelist will be created.
  • Configure Permissions - OnlyOneMessage will assign the blacklist role to the set channel, and assign restrictions to it.
💡

You can change the names of the blacklist & whitelist roles and OnlyOneMessage will respect it. [Only applies if your server is setup on v1.5 or higher].

The confirmation embed from running /setup.

3. Customization

You can customize your channels and roles to your liking. You can also customize bot behavior with /config.

If you would like to know a detailed list of commands, refer to the Commands section.
