API Reference

Access insights from OnlyOneMessage through our REST API, available since version 1.7. This API is used on our OnlyOneMessage website and status page.

This API is available at https://oomapi.monobyte.studio.

💡

This API is currently a work in progress. You may encounter occasional issues. If you do, please join our Support Server and create a ticket so we can patch it up.

/v1/stats

Method: GET

Retrieve general statistics about OnlyOneMessage. Data includes its version, message metrics, latency, and more. 

GET https://oomapi.monobyte.studio/v1/stats
{
    "version": "major.minor.micro",
    "build": "year.month.day",
    "latency": [int in milliseconds],
    "uptime": [int in seconds],
    "shards": [int],
    "guilds": [int],
    "members": [int],
    "channels": [int],
    "whitelists": [int],
    "blacklists": [int],
    "totalmsgs": [int]
}

/v1/health

Method: GET

Check the bot's online status and shard latencies. 

GET https://oomapi.monobyte.studio/v1/health
{
    "database": "[online/offline]",
    "health": "online",
    "shards": {
        "[shard id]": {
            "latency": [int in seconds],
            "status": "[online/offline]"
        }
    }
}
⚠️

If the server doesnt respond, OnlyOneMessage is offline.
